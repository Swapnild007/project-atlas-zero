# Product vision and national-impact criteria

Project Atlas Zero is an independent open-source engineering initiative. It is not affiliated with or endorsed by the Government of India.

## Mission
Build in India. Serve India. Compete globally.

## Initial user groups
1. Students and educators: verifiable multilingual explanations and learning.
2. MSMEs: assisted documentation and workflow automation.
3. Developers: safe coding and research agents.

## Release gates
P0: real chat, durable conversations, error handling, authentication, automated tests.
P1: source-grounded retrieval, Hindi/Marathi/English evaluation sets, MCP permissions, observability.
P2: isolated coding sandbox, public impact study, independent security assessment, inclusive accessibility.

## Responsible AI
Track accuracy, hallucinations, Indian-language performance, cost, latency, security incidents and accessibility. Provide human approval for consequential actions. Minimize personal data and document provenance. Never imply government endorsement.

## Infrastructure
Budget: INR 0/month. BYO hosted API keys. Local SQLite for development; do not deploy ephemeral SQLite as durable serverless storage. Public hosting requires authenticated API, rate limiting and durable managed database.

## Government-readiness evidence
Public reproducible benchmarks, documented social outcomes, lawful dataset licensing, privacy and security controls, project governance, and transparent cost reporting.
